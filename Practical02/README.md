# Practical 2 – Data Cleaning and Missing Data Handling

## Objective

Clean real-world datasets and handle missing or invalid data using R.

## Lab 3 – Heart Disease Data Cleaning

* Worked with the Cleveland Heart Disease dataset.
* Inspected data structure and identified invalid/missing blood pressure values.
* Applied median imputation to clean blood pressure data.
* Validated the cleaned dataset.

## Lab 4 – Missing Data Handling

* Worked with the UCI Adult Income dataset.
* Identified and handled `NA`, `NaN`, `NULL`, and blank values.
* Detected invalid values and missing categorical data.
* Applied median imputation for numerical variables.
* Analyzed and visualized missing data using `naniar`.
* Exported the cleaned dataset.

## Key Topics

* Data inspection and cleaning
* Missing-value detection
* Invalid-value handling
* Median imputation
* Categorical data cleaning
* Missingness visualization
* Data validation
* CSV data export
